# WAVE: проверка плеера Telegram Mini App

Минимальный эксперимент с HTML-аудиоплеером: две синтезированные мелодии по 12 секунд, очередь, автоматический переход и экспорт журнала. Сторонние музыкальные записи и токены не используются.

## GitHub Pages

Готовый статический сайт находится в `docs/`. В GitHub откройте Settings → Pages → Build and deployment → Deploy from a branch, выберите ветку `main`, папку `/docs` и сохраните настройки. Адрес опубликованного сайта отображается там же после завершения развёртывания.

Пути к аудио относительные и поддерживают публикацию проекта в подпапке GitHub Pages. Python для опубликованной версии не нужен.

## Локальная проверка

Из корня репозитория:

```sh
python3 -m http.server 8000 --directory docs --bind 127.0.0.1
```

Для исходной версии с генерацией WAV во время запуска:

```sh
python3 server.py --port 8000
```

## Проверка на устройстве

Сначала проверьте воспроизведение и переход на вторую мелодию при открытом экране. Затем повторите с блокировкой экрана на 20 секунд и отдельно со сворачиванием Telegram. Для проверки именно Mini App откройте HTTPS-страницу через настроенное приложение своего тестового бота в BotFather; обычная ссылка может открыться в браузере, и такой результат не подтверждает поведение Mini App.

После каждого сценария скачайте журнал и запишите устройство, ОС, версию Telegram и был ли слышен звук. Журнал браузера не доказывает слышимость. Работа в фоне и управление с экрана блокировки пока не подтверждены. Перезагрузка страницы очищает журнал.

Это технический прототип без пользователей, подписок, поиска и коммерческого музыкального каталога.
