# WAVE

Личный музыкальный плеер внутри Telegram Mini App.

- Коллекция аудио из профиля Telegram через `getUserProfileAudios`.
- Поиск в каталоге Audius и по загруженным трекам, пагинация.
- «Моя музыка» с добавлением и удалением треков внутри WAVE.
- «Для вас»: подборка по исполнителям и жанрам последних 15 прослушанных треков.
- Очередь, воспроизведение, пауза, перемотка и повтор.
- Полноэкранный плеер с обложкой из Telegram, если она доступна.
- Анимированный индикатор воспроизведения; он не является анализатором звука.
- Сезонная тема Halloween и базовая тема.

Адреса файлов Telegram кэшируются в памяти на 15 минут; параллельные запросы
делят один lookup. При открытии коллекции подготавливается первый трек, затем — следующий.
На VPS аудио временно хранится в приватном файловом кэше: до 256 МиБ, до двух
часов с очисткой раз в минуту. Готовые файлы переживают перезапуск сервиса;
неполные удаляются. Начало файла передаётся по мере загрузки, без ожидания
скачивания всей записи. Подготовка не гарантирует бесшовное воспроизведение:
скорость первого получения файла из Telegram и сеть устройства влияют на запуск. Обложки могут храниться только в личном браузерном
кэше до минуты. Список коллекции при переключении не создаётся заново.

## Запуск

Node.js 22.13+ (на VPS 22.22.1), без npm-зависимостей. Нужны серверные переменные `BOT_TOKEN`,
`FRONTEND_ORIGIN` (публичный HTTPS-origin без завершающего слеша), `HOST` и `PORT`.

```sh
node backend.mjs
```

Подробности: [развёртывание на VPS](deploy/README.md).
Токен бота хранится только на сервере. GitHub Pages может обслуживать интерфейс,
но для доступа к личной музыке необходим backend.

## Темы

Оформление отделено от воспроизведения в `docs/theme.css`. По умолчанию включена
тема Halloween. Для базовой темы установите `WAVE_THEME=default` в серверном
файле окружения и перезапустите только сервис WAVE. Для Halloween используйте
`WAVE_THEME=halloween` или не задавайте переменную. В статической публикации
аналогичная настройка находится в `docs/config.js`.

## Проверки разработки

```sh
node tests/profile.test.mjs
node tests/http.test.mjs
node tests/audio-cache.test.mjs
node tests/audius.test.mjs
node tests/personal.test.mjs
node tests/i18n.test.mjs
```

Для измерения задержек на VPS после запуска трека: `python3 scripts/check-audio.py`.
Скрипт не выводит токен, название композиции или подписанную ссылку.

Автоматические проверки используют искусственные ответы Telegram. На устройстве
пользователя отдельно проверены музыка профиля, воспроизведение, перемотка и
переходы с заблокированным экраном в предыдущей версии интерфейса. Новое оформление
и большой экран плеера требуют повторной проверки на устройстве после обновления.

## Поиск в каталоге Audius

Добавлена вкладка «Найти музыку»: поиск вне профиля, пагинация и воспроизведение
открытых треков через существующий плеер. Для подключения нужны серверные
`AUDIUS_API_KEY` и `AUDIUS_BEARER_TOKEN`. Пока они не настроены, вкладка скрыта.
Готовые ключи проверены владельцем на VPS: доступны поиск и начало аудиопотока.
Полное воспроизведение нового источника в Telegram нужно проверить после
развёртывания. Audius не является каталогом всей популярной музыки.

Подключение и ограничения: [Audius](deploy/audius.md).

## Личная библиотека и рекомендации

«Из профиля» показывает музыку Telegram. Кнопка «+» сохраняет выбранный трек
в «Мою музыку» WAVE; она не добавляет и не удаляет аудио в профиле Telegram.
Коллекция привязана к подтверждённому Telegram ID, сохраняется на сервере и
доступна после переоткрытия приложения и на другом устройстве.

SQLite встроен в Node: файл `library.sqlite` лежит в `WAVE_DATA_DIR`, если он
задан, иначе в `STATE_DIRECTORY` (`/var/lib/wave` у systemd). При локальном
запуске запасной путь — системная временная папка `wave-personal`.
Коллекции и история не входят в очищаемый аудиокэш. Подписанные ссылки в базе
не хранятся: при открытии коллекции создаются новые. Не удаляйте базу при
очистке кэша; для резервного копирования используйте SQLite backup API или
снимок каталога после остановки WAVE, включая WAL-файлы, если они есть.

История учитывает продвижение аудио во время воспроизведения: минимум 15 секунд
или половину трека, если он короче 30 секунд. Пауза, буферизация и перемотка
не прибавляют время. Это история событий плеера, не доказательство слышимости
и не отчёт для начисления роялти. Хранятся последние 100 событий на пользователя;
для подборки берутся 15 последних разных треков. Подборка сочетает знакомых
исполнителей и новые группы близкого жанра. Жанровые кандидаты берутся через
`/tracks/trending?genre=…`, а не текстовый поиск. Рейтинг учитывает жанр,
настроение, теги и BPM, если Audius их указал. Название не участвует в оценке
похожести; результаты поиска исполнителя проходят проверку поля исполнителя.
На одного исполнителя приходится не больше трёх песен на страницу; страницы
выдаются порциями до 20 треков. Уже
прослушанные и сохранённые песни исключаются. Это сходство по метаданным,
не анализ самого аудиосигнала. Если у истории нет жанров, остаётся подборка
по знакомым исполнителям. Начальная подборка кэшируется на пять минут;
явное обновление обходит этот кэш и исключает уже выданные треки. Новая
история и изменения коллекции также обновляют начальную подборку. Без
истории или доступных совпадений список остаётся пустым.

Поле поиска имеет шрифт 16px, чтобы iOS не увеличивала его при фокусе. Масштаб
ограничен настройками viewport и обработчиками жестов; отдельное касание вне поля
снимает фокус. Перетаскивание и прокрутка сохраняют фокус и клавиатуру. Поведение системной клавиатуры и жестов нужно дополнительно проверить
в Telegram на реальном iPhone.

При фокусе на поиске тот же мини-плеер перемещается наверх и занимает одну
строку; кнопки паузы и переключения доступны без закрытия клавиатуры. При
изменении видимой области из-за клавиатуры поле остаётся ниже плеера. Обычная
прокрутка не возвращает страницу к полю и не меняет положение мини-плеера.

На Telegram 8.0+ приложение запрашивает полный экран при открытии. Кнопка
«На весь экран» позволяет войти повторно после выхода или отказа клиента.
Системные и контентные safe-area отступы учитываются отдельно, включая
полноэкранный плеер и поиск. Цвета шапки, фона и нижней панели Telegram берутся
из темы WAVE. Цвет системных кнопок закрытия и меню определяет Telegram;
Mini App API не предоставляет настройку их заливки.

На Telegram 7.7+ `disableVerticalSwipes()` отключает сворачивание жестом по
содержимому. Прокрутка страницы не блокируется; системную шапку по-прежнему
можно тянуть вниз. Упругое растягивание при достижении края зависит от WebView
устройства. Старые клиенты продолжают использовать свои штатные жесты.

## Язык интерфейса

Интерфейс автоматически использует `Telegram.WebApp.initDataUnsafe.user.language_code`.
Если язык Telegram отсутствует, берётся `navigator.language`. Поддерживаются
русский и английский; для остальных языков используется английский. Для этого
не нужны IP-геолокация или разрешения устройства. В профиле можно выбрать
«Авто / Русский / English»; выбор хранится локально для текущего Telegram ID.
Язык меняется без перезагрузки и остановки музыки. Названия треков и имена
исполнителей не переводятся: повторная локализация меняет только исходные
элементы интерфейса. Отдельной шестерёнки настроек больше нет. Переводы
интерфейса и сообщений хранятся в `docs/i18n.js`.

## Приоритет исполнителей и профиль WAVE

Каталог объединяет полный индекс Audius (`/search/full`), обычный поиск
треков и каталоги найденных исполнителей. Имена сравниваются с учётом
акцентов, пунктуации и небольших опечаток; для кириллицы добавляется транслит,
для «Король и Шут» — также «КиШ». Запрос «исполнитель — песня» фильтрует каталог
исполнителя по названию. Результаты дедуплицируются и ранжируются: доступность
воспроизведения, совпадение исполнителя, название, затем остальные совпадения.
Совпадение только начала слова в имени получает меньший приоритет.

Каталоги исполнителей читаются постранично, без прежнего ограничения на
первые 40 песен. До 64 снимков выдачи живут в памяти десять минут; пустой
результат кэшируется на 15 секунд. Снимок содержит до 1000 треков, новые
страницы добавляются без перестановки уже выданных строк. Идентификатор снимка
позволяет продолжать выдачу без повторов и пропусков. Кнопка повторного поиска
создаёт новый снимок, не нарушая чужую или уже открытую пагинацию. Отказ одного
индекса не выключает оставшиеся. Каждый поиск имеет ограниченный сетевой
бюджет; общее число результатов не выдумывается.

Найти можно только записи, существующие в Audius. Наличие песен любого
известного исполнителя не гарантируется. Проверка с реальными ключами на VPS:

```sh
node --env-file=/etc/wave.env scripts/check-search.mjs "король и шут" queen
```

Скрипт выводит число ответов, использованные варианты и первые названия,
но не ключи, подписанные ссылки или адреса аудиопотоков.

Во вкладке «Для вас» нет поля поиска и не применяется скрытый текстовый фильтр.
При открытом поиске внешний viewport блокируется, а прокрутка выполняется
внутри `.shell`; мини-плеер находится за пределами этого скроллера. Его высота
от верхнего края постоянна и не пересчитывается при событиях прокрутки
`visualViewport`. При закрытии поиска восстанавливается текущая позиция страницы.

Иконка человека в шапке открывает профиль WAVE: имя, username
Telegram и число сохранённых треков, а также переход в «Мою музыку».
`POST /api/account` использует подтверждённый Telegram ID из `initData`,
не принимает чужой `user_id` и не запрашивает профиль у сторонних сервисов.

## Компактный интерфейс и автоматическое продолжение

Успешные загрузки не сопровождаются служебными подписями под заголовками.
Загрузка и ошибки остаются видимыми. При успешном сохранении из списка рядом
с той же строкой на 2,8 секунды появляется сообщение «Добавлено в мою музыку»;
до ответа сервера и при ошибке оно не показывается. Полоски логотипа WAVE
анимируются только при фактическом воспроизведении; на паузе возвращается
исходная симметричная форма с высокой центральной полоской.
`prefers-reduced-motion` отключает анимацию.

Верхний промоблок содержит четыре визуальные карточки и переходы в «Для вас»,
«Найти музыку», «Моя музыка», «Из профиля». Каждая карточка остаётся на экране
пять секунд после завершения предыдущего перехода, затем за две секунды
плавно сдвигается влево. Нажатие кнопки перехода в раздел не останавливает
автоматическую смену карточек.
Есть ручные индикаторы и пауза; таймер приостанавливается в скрытом приложении,
при фокусе на карточке и при уменьшенном движении в настройках устройства.

Рекомендации подгружаются по 20 при приближении к концу списка, а также заранее
за три песни до конца играющей очереди. По завершении последней загруженной
песни плеер получает следующую страницу и продолжает без «Показать ещё».
Переключение разделов и обновление видимого списка не подменяют уже играющую
очередь. Стрелка обновления запрашивает другую похожую подборку без уже
показанных треков; если подходящие записи в Audius исчерпаны, повторы не
создаются искусственно.

Продолжение использует непрозрачный курсор с привязкой к пользователю и
подключению Audius. Последние три страницы можно повторно запросить без
пропусков; параллельные запросы одной страницы объединяются. В памяти хранится
до 500 лент; неактивные курсоры истекают через 12 часов. Перезапуск сервиса
требует обновить подборку. Существующие сроки авторизации Telegram (один час)
и подписанных ссылок (два часа) остаются в силе: при истечении сессии приложение
попросит переоткрыть WAVE. Продолжение не является гарантией бесконечного
каталога или бесшовного аудиоперехода.

При обновлении текущие треки остаются видимыми до успешного ответа сервера.
Ошибка сохраняет предыдущий список. При переключении между списками разной
длины высота области меняется плавно, чтобы не было мгновенного скачка
прокрутки. Всплывающие сообщения используют тёмные цвета активной темы.

На поддерживаемых клиентах Telegram короткий тактильный отклик сопровождает
переключение разделов (`selectionChanged`) и нажатия кнопок управления
(`impactOccurred('light')`). Автоматические переходы очереди и карусели не
вызывают вибрацию. Повторные события одной кнопки в пределах 100 мс
объединяются, а отсутствие поддержки не мешает работе приложения.

## Аватар и неподвижный экран трека

Профиль получает подписанный адрес `/api/avatar`: изображение загружается
отдельно от имени и счётчика. Сервер вызывает `getUserProfilePhotos` для
подтверждённого Telegram ID, выбирает размер около 160 px и передаёт фотографию
через существующий приватный маршрут обложек. Файловые идентификаторы
кэшируются до десяти минут; при скрытом или недоступном фото остаются инициалы.
Токен бота и прямые адреса Telegram не передаются клиенту.

Экран трека блокирует прокрутку себя и страницы под ним. При закрытии
восстанавливается прежняя позиция страницы. Размер квадратной обложки
подстраивается под оставшуюся высоту, перемотка и остальные кнопки доступны.
Нижний декоративный слоган удалён. Поиск повторяет высоту и круглые края
панели разделов (42 px на телефоне, 48 px на широком экране), сохраняя шрифт
16 px для предотвращения увеличения поля в iOS.

Событие `stalled` означает задержку загрузки, но не обязательно остановку
звука: оно больше не выключает индикаторы. Продвижение аудио восстанавливает
состояние воспроизведения, если WebView не прислал повторное событие `playing`.
Пауза, ошибка и фактическая буферизация по-прежнему останавливают движение.

Панель разделов теперь состоит из четырёх фиксированных колонок, без
горизонтального скролла. На узком экране подписи уменьшаются, а вертикальная
прокрутка страницы остаётся доступной.
