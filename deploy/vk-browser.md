# Вход в VK из браузера на VPS

Эта временная среда нужна для ручного входа владельца с IP VPS. Она не подключает
каталог VK к WAVE, не выполняет поиск и не подтверждает доступность полного аудио.
Успешный вход и воспроизведение в браузере нужно проверить отдельно.

Предварительно установлены `google-chrome`, `xvfb`, `x11vnc`, `novnc`, `websockify`,
`xauth`, `openbox` и `dbus-run-session`. На VPS пользователя доступны 3.8 ГиБ RAM
и 35 ГиБ диска; порты 5900 и 6080 перед установкой были свободны.

1. На Mac в отдельном терминале подключитесь к VPS с туннелем и оставьте окно
   открытым:

   ```sh
   ssh -o ExitOnForwardFailure=yes -L 6080:127.0.0.1:6080 root@13.143.249.62
   ```

2. На сервере:

   ```sh
   cd /opt/wave
   git pull --ff-only origin main
   python3 scripts/vk-browser.py start
   ```

   Первый запуск попросит отдельный пароль VNC (8 символов, ввод скрыт), повтор
   пароля и подтверждение сохранения `y`. Не используйте пароль VK. Пароль не
   передаётся в командной строке и не отправляется в чат.

3. После сообщения «Готово» в обычном Chrome на Mac откройте:

   ```text
   http://127.0.0.1:6080/vnc.html?autoconnect=true&resize=scale&path=websockify
   ```

   Введите пароль VNC. Откроется окно Chrome на сервере. Вход VK, SMS, QR или
   другое штатное подтверждение выполняйте самостоятельно внутри этого окна.
   Не присылайте пароль, код, QR входа или Cookie. Проверьте поиск и прослушивание
   песни в этом браузере. Антибот-проверки не обходятся и успех входа не обещается.

4. После проверки остановите временный браузер:

   ```sh
   cd /opt/wave
   python3 scripts/vk-browser.py stop
   ```

Браузер работает отдельным непривилегированным пользователем `wave-vk` без shell.
Профиль и вход находятся в закрытом `/var/lib/wave-vk/profile` (0700 на родительской
папке). Файл VNC-пароля приватный. Остановка сохраняет профиль, не удаляет учётную
запись и программы; при необходимости отзовите вход в настройках безопасности VK.
Профиль не входит в git и не копируется в среду Codex. Доступа к `/etc/wave.env`
этому пользователю не предоставляется.

Xvfb использует Xauthority и не слушает TCP. VNC и noVNC слушают только IPv4
loopback на VPS. Nginx, внешние порты и firewall не перенастраиваются.
Доступ с Mac идёт через SSH; открывать 5900/6080 наружу нельзя. Служба временная,
не добавляется в автозапуск, останавливается через 2 часа. Ограничена 1536 МиБ
RAM и 512 задачами. Песочница Chrome и проверка TLS не отключаются.

`systemd` здесь требуется для запуска; live-запуск на конкретном VPS ещё должен
быть проверен пользователем. Локальные проверки политики запуска:

```sh
python3 tests/vk-browser.test.py
```

При ошибке скрипт выводит последние сообщения собственной службы. Логи дочерних
процессов не печатаются: из них выводятся только фиксированные категории ошибок.
Нельзя отправлять полный браузерный профиль или необработанные логи с VK URL.
